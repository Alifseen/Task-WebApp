# To Do App with Streamlit
This was my first attempt at creating a fully functioning application with a boilerplate library such as streamlit.

I used things like session state manipulation to store information and process it.

Speaking of processing, I used functional programming and separated the backend to run it as a local module.

P.S = I was transitioning from JS to Python so I created a few variables in Camel Case, I learned later that that was reserved for class methods only.
